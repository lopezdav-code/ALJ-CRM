⚙️ Configuration

Cette page télécharge la base database_Competition.db depuis votre Google Drive (connexion Google), la garde en cache du navigateur (IndexedDB) et permet de la modifier. Les modifications restent locales : elles ne sont renvoyées vers Google Drive qu'après un clic explicite sur le bouton « 💾 Sauvegarder en BDD ».

L'identifiant du fichier database_Competition.db sur le Drive est pré-rempli avec celui du club (comme l'ID client OAuth) : modifiable ici si le fichier change — l'accès reste contrôlé par les autorisations Drive.

⚠️ Dans Google Cloud Console (API et services → Identifiants → ID client OAuth), cette adresse doit être listée en URI de redirection autorisée (sinon erreur 400 redirect_uri_mismatch) :
