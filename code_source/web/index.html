⚙️ Configuration

Cette page affiche l'annuaire des adhérents en lecture seule. Elle télécharge la base database.db depuis votre Google Drive (connexion Google), puis la garde en cache du navigateur (IndexedDB). Le bouton 🔄 recharge une version à jour ; sans connexion, la dernière base en cache reste utilisable.

Configuration (une seule fois) :

  1. ID client OAuth : Google Cloud Console → API & Services → Identifiants → créer un ID client OAuth de type Application Web (API Google Drive activée).
  2. Dans cet ID client, ajoutez en URI de redirection autorisée l'adresse exacte de cette page :
    (et pour un usage local : http://localhost:8000/annuaire/)
  3. ID du fichier database.db sur le Drive : visible dans l'application de bureau (onglet Paramètres → secret GOOGLE_DRIVE_DB_ID)
  4. Collez les deux valeurs ci-dessous puis appuyez sur « Se connecter » : le navigateur est redirigé vers la page d'authentification Google, puis revient automatiquement ici avec la base.
