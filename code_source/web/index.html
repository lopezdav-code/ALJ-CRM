L'annuaire des adhérents est réservé aux coachs et gestionnaires du club. Les données sont lues en temps réel dans la base du club (Google Cloud Firestore) : toute modification faite dans l'application de bureau apparaît ici automatiquement. Cette page est en lecture seule.
